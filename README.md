# TripFlow

지도에서 여행 동선을 짜고 이동시간, 주변 장소, 블로그 후기를 확인하는 단일 HTML 웹앱입니다.

- 사이트: https://youncall31-glitch.github.io/tripflow/
- 처음 열면 그림으로 된 사용법이 나옵니다. '다시 보지 않기'로 끌 수 있고, 오른쪽 위 '사용법' 버튼으로 다시 볼 수 있습니다.
- 일정과 설정은 사용하는 기기의 브라우저에만 저장됩니다. 계정·키 없이 동작합니다.
- 여러 날짜 일정, 종료 시간, 핀을 끌어 위치 수정, 구글맵 하루 길찾기·구글 내 지도(KML) 내보내기를 지원합니다.
- 화면 맨 위 검색창 아래 🌴 발리 / 🍊 제주 버튼으로 여행지를 바꿔요. 여행지마다 일정·선택 지역이 따로 저장됩니다.
- 일정 공유: 동선 탭 아래 '공유 링크 보내기'로 카카오톡 등에 링크를 보내면, 받은 사람이 열어서 같은 일정을 가져올 수 있습니다. 일정은 링크 주소의 # 뒤에 압축돼 담기며 서버에 저장되지 않습니다(실시간 동기화는 아님).
- 검색하면 결과가 바로 지도에 번호 핀(검은색)으로 표시됩니다. 위쪽 검은 막대의 목록 버튼으로 이름·거리 목록을 볼 수 있습니다.
- 꼭 가고 싶은 곳은 ☆ 찜으로 시간 없이 저장하면 지도에 노란 별로 늘 표시됩니다. 찜 탭에서 원할 때 동선에 추가할 수 있습니다.
- 장소 검색·주변·지역별 인기 장소는 `data/bali-places.json`, `data/jeju-places.json`(Overture Maps 오픈 데이터 + 위키데이터 + 네이버 블로그 언급 수)을 사용합니다. GitHub Actions의 '여행지 장소 데이터 만들기' 작업이 매주 갱신합니다.
- 국내 지점 검색은 앱의 지도 설정 → '카카오 장소 검색'에서 본인의 카카오 JavaScript 키를 연결하면 사용할 수 있습니다. 키는 저장소에 포함되지 않습니다.
