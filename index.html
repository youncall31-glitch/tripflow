    카카오 장소 검색 연결

    국내 식당·카페를 지점까지 찾으려면 카카오 개발자 사이트의 무료 JavaScript 키가 필요해요.

    1. 카카오 디벨로퍼스 → 내 애플리케이션에서 앱을 만들어요.
    2. [제품 설정] → [카카오맵]에서 사용 설정을 켜요.
    3. [앱] → [플랫폼 키] → [JavaScript 키]를 복사해 아래에 붙여 넣어요.
    4. 같은 화면 [JavaScript SDK 도메인]에 이 주소를 등록해요.

      파일로 직접 연 페이지에선 키가 동작하지 않아요. 웹 주소(예: GitHub Pages)로 올려서 열어 주세요.
